# Phase 2.4 — Ag03 滑动窗口限流

## Summary

实现了滑动窗口限流器（Sliding Window Rate Limiter），为 EngramDB 提供轻量级、原子性的请求速率控制原语，适用于 Agent 网关的 LLM API 限流、用户请求限流、熔断保护等场景。

## 设计

- **滑动窗口计数器**：每个 key 维护一个 `VecDeque<Instant>` 时间戳队列
- **check(key, limit, window_secs)**：移除过期时间戳，检查队列长度是否超出限制
- **increment(key, window_secs)**：追加当前时间戳，用于仅计数不限制的场景
- **内存可控**：`VecDeque` 最大长度 = `limit`，每个 key 最多存 limit 个时间戳
- **自动清理**：`check()` 和 `increment()` 时自动触发过期清理

## 文件

### `src/storage/rate_limiter.rs`

- `RateLimiter` 结构体：`HashMap<String, VecDeque<Instant>>` + `RateLimiterStats`
- 核心方法：`check()`, `increment()`, `count()`, `reset()`, `clear()`
- 统计方法：`stats()`, `active_keys()`
