# Phase 2.3 — Ag02 嵌入式 KV 缓存引擎

## Summary

实现了嵌入式 KV 缓存引擎，为 EngramDB 提供内置的 LRU + TTL + 命中率统计缓存，替代应用层 Redis/Memcached，减少部署依赖。

## 设计

### SLRU（Segmented LRU）双队列

- **Probation（试用区）**：新条目进入此队列尾部，淘汰时优先从尾部淘汰
- **Protected（保护区）**：条目被再次访问时晋升到此区，淘汰时从尾部降级到 probation
- **保护比例**：protected 占 80%，probation 占 20%（基于 80/20 法则）
- **扫描抵抗**：全表扫描只污染 probation 区，不污染 protected 区

### TTL 桶式过期

- 使用 `BTreeMap<u64, Vec<u64>>` 按过期时间秒分组
- 淘汰时 O(log n) 定位过期桶，O(k) 删除过期条目
- 在 `get()` 和 `evict_until_under_budget()` 中均会触发

### 内存预算

- 按字节计费，插入时自动淘汰直到低于预算
- 默认 64MB，可通过 `set_cache_size()` 调整
- 淘汰优先级：过期条目 > probation 尾部 > protected 尾部降级

## Changes

### 新文件 (`src/storage/cache.rs`)

- `KVCache` 结构体：entries (HashMap) + probation (VecDeque) + protected (VecDeque + HashSet) + ttl_index (BTreeMap)
- `CacheEntry` 结构体：value, size, created_at, hit_count, ttl_seconds
- `CacheStats` 结构体：hits, misses, evictions, entries, memory_used
- 核心方法：`get()`, `insert()`, `remove()`, `clear()`, `evict_expired()`, `set_max_memory()`
- 统计方法：`stats()`, `hit_rate()`, `memory_usage()`
- 7 个单元测试

### Database (`src/storage/mod.rs`)

- 新增 `kv_cache: KVCache` 字段，默认 64MB
- `create_new()` 和 `open_existing()` 构造函数中初始化
- 新增 `cache()` 访问器方法

### Connection API (`src/lib.rs`)

- `set_cache_size(bytes)` — 设置缓存预算
- `cache_stats()` — 获取缓存统计（命中率、条目数等）
- `clear_cache()` — 清空缓存
- `cache()` — 获取底层 KVCache 可变引用
