# v0.18 LogEngine 写入优化计划

目标：从 90 万行/秒（M3 批量基准）冲上 500 万行/秒级，核心思路
「能攒就攒、能异步就异步、能少拷贝就少拷贝」。

## 现状核对（动工前对照代码的结论）

| 方案 | 代码现状 | 结论 |
|---|---|---|
| WAL 组提交 | **已实现且默认开启**（config size=16 / 64KB，commit 锁内合并，Perf04 5-10x） | 非新增，补时间窗 |
| 冻结异步化 | **前提不成立**：写入期零冻结（ensure_typed 惰性） | 废弃 |
| 列编码延迟 | **已实现**：写入期只存 Vec\<Value\> | 已兑现 |
| insert_columns | **反模式**：列→行→列双重转置 + 每值 2 次 clone | 真实高 ROI |
| row_id 分配 | **M3 遗留 bug**：insert/insert_columns 循环后才推进 next_row_id，块满新建时 row_id_base 全为 0，多块二分失效（默认 8192 单块场景碰巧掩盖） | 必修 |

## P0 · v0.18 首批（已完成 ✅）

### P0-1 列式直写 insert_columns
- `src/storage/log_engine.rs`：按列整段 move 进块缓冲（每值零克隆），MinMax 段级
  维护，块满按 block_rows 切分；append_row 借用 `&Value`（每值仅 1 次克隆）
- 收益：批量落盘（apply_to_storage / import_columns / 恢复重放）20-40%

### P0-2 INSERT 攒批合并（Batcher）
- `src/storage/insert_batcher.rs`：Database 内嵌 InsertBatcher，autocommit 逐行
  INSERT 攒批（行数 1024 / 字节 64KB / 时间窗 10ms 任一触发 → 单事务批量落盘）
- 语义边界：
  - 显式事务内跳过（`in_explicit_txn`：SQL BEGIN / Transaction API）
  - 有约束表跳过（NOT NULL / PK / UNIQUE / 自增 / TTL / 外键——约束错误须
    在该语句返回时暴露；`table_has_constraints`）
  - INSERT ... RETURNING 绕过（需立即读回插入行）
  - 非裸 INSERT 语句 / begin / close / sync_wal / checkpoint / import_columns
    前置 `flush_all_batched`（读己之写 + 行序）
  - 崩溃丢缓冲行 = 与 WAL 组提交一致的异步窗口（close 兜底冲刷）
- 收益：逐行场景 **27x**（4 万 → 107 万行/秒实测）

### P0-3 时间窗式组提交
- `src/wal/writer.rs`：距上次 fsync 超过 `wal_group_commit_timeout_ms`（默认 10ms）
  则下次 commit 强制 sync——低流量场景持久化延迟有界（count/bytes 阈值不再
  是唯一触发器）

## P1 · v0.18 后段（已完成 ✅）

### P1-4 冻结即释放写入缓冲
- LogBlock::ensure_typed 后冻结块（rows ≥ block_rows）释放 columns 写入缓冲，
  点查改走 typed 缓存——Log 表内存占用减半（Value 对象层不复存在）
- 注：原始"块缓冲池复用"方案在 Log 架构无回收源（旧块必须驻留供扫描/
  序列化），改为释放 + typed 全功能替代，收益更直接

### P1-5 块大小可配置
- `Config::log_block_rows`（0 = 默认 8192）→ `LogTable::with_block_rows`；
  影响冻结频率 / MinMax 跳读粒度 / 序列化块头摊销；不写入文件（仅新块）

### 修复：row_id 分配（M3 遗留）
- insert / insert_columns 循环内逐段推进 next_row_id，块满新建时 row_id_base
  正确；多块二分定位 / 恢复幂等（row-exists skip）/ 范围跳读全部恢复正确

## 基准（benches/v018_write_bench.rs）

| 场景 | 结果 |
|---|---|
| 批量 import_columns 100 万行 | **1623 万行/秒**（列式直写） |
| SQL 批量写入 100 万行（M3 口径） | **104 万行/秒**（原 90 万，+15%） |
| 逐行 INSERT（Batcher 开） | **107 万行/秒** |
| 逐行 INSERT（Batcher 关） | 4 万行/秒（**27x**） |
| 低流量持久化窗口 | 15ms 有界（时间窗生效） |
| A 系列验收 | 零退化（B-4 0.65x / A-4 0.30x） |
