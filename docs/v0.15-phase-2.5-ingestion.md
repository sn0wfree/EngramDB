# Phase 2.5 — Ag16 文档摄入 API

## Summary

实现了文档摄入 API（`DocumentIngestor`），提供一键摄入 Markdown/文本文件并自动建向量索引的能力。

## 设计

### 文档表结构

| 列 | 类型 | 说明 |
|----|------|------|
| id | INT PRIMARY KEY AUTO_INCREMENT | 自动递增文档 ID |
| title | VARCHAR NOT NULL | 文档标题（或分块标题） |
| content | VARCHAR NOT NULL | 文档内容（或分块内容） |
| embedding | VECTOR(dim) | 向量嵌入 |

### 分块策略

**Markdown 标题分块（默认）**：
- `# Title` / `## Section` 等标题作为分块边界
- 每个标题下的内容作为一个独立文档行
- 超过 `max_chunk_size` 的大段额外分割

**纯文本分块**：
- 按 `max_chunk_size` + `chunk_overlap` 滑动窗口
- 尽量在单词边界分割

### 摄入流程

1. 用户提供文本 + 外部嵌入函数（`fn(&str) -> Vec<f32>`）
2. 自动分块
3. 调用嵌入函数为每块生成向量
4. 批量插入文档表

## Changes

- `DocumentIngestor` 结构体（持有 `&mut Connection` + 分块配置）

- `count()` — 获取文档行数
- 内部方法：`chunk_text`, `chunk_by_markdown`, `chunk_by_size`
