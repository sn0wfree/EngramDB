# Phase 2.1 — V07 混合查询（向量 + 标量 pre-filter）

## Summary

实现了混合搜索 API：先通过 HNSW 向量索引获取候选集，再对每个候选行应用标量条件过滤，返回满足条件的 Top-K 结果。支持可调节的候选集扩大倍数（ef_mult），在召回率与性能之间灵活平衡。

## Changes

### API (`src/lib.rs`)

- 新增 `HybridSearchResult` 公有结构体：
  - `row_id: u32` — 行 ID
  - `distance: f32` — 与查询向量的距离
  - `row: Vec<Value>` — 投影后的行数据（按 `column_indices` 过滤）

- 新增 `Connection::database_mut()` — 暴露底层 `Database` 的可变引用，用于高级 API 操作

### Database (`src/storage/mod.rs`)

- 新增 `Database::hybrid_search()` 方法，流程：
  1. 用 HNSW 搜索 `top_k * ef_mult` 个候选（扩大 ef 提高召回率）
  2. 通过 `id_mapping` 将 HNSW 内部 ID 映射为表 row_id
  3. 对每个候选行，调用 `filter_fn` 标量过滤闭包
  4. 过滤后的结果按距离升序排列，取 Top-K
  5. 返回 `Vec<HybridSearchResult>`（含 row_id、distance、投影行数据）

### HNSW Index (`src/storage/vector_index.rs`)

- 新增 `HnswIndex::config()` — 公开索引配置（含 `ef_search`），用于混合搜索的动态候选集扩大

## Test

- `test_hybrid_search`: 6 行数据，3 个类别各 2 行，验证：
  - 无过滤的纯向量搜索
  - 过滤类别 A 的结果（返回 2 行）
  - 过滤类别 B 的结果（返回 2 行）
  - 过滤不存在的类别 Z（返回 0 行）
