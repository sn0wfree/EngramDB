# Phase 3.5 执行计划 — Auto 迁移 MVCC + mmap 跨平台 + Bloom 索引化

> **版本**：v0.26.0 Phase 3.5
> **基线**：v0.25.0 Phase 3（commit `a497226`，2026-09-04）
> **分支**：`phase3.5/mvcc-mmap-bloom`
> **工期**：2-3 周

---

## 一、阶段目标

完成 Phase 3 推迟的三项关键改进：

1. **Auto 迁移 MVCC 集成**（P0）— 迁移后版本链完整 + Memory/Log 标记同步
2. **mmap 跨平台 + 大文件**（P1-A）— Windows 兼容 + > 4GB 文件
3. **Float/Varchar Bloom 索引化**（P1-B）— 避免每次 `may_contain` 全表扫描

---

## 二、关键 KPI（10 轮 P50）

| KPI | Phase 3 末 | Phase 3.5 目标 |
|---|---|---|
| 迁移后 MVCC 一致性 | 不验证 | **零版本链损坏** |
| mmap 跨平台 | 仅 Linux/macOS | **+ Windows** |
| mmap 大文件支持（> 4GB） | ❌ | **✅** |
| Bloom may_contain 调用延迟 | O(7) 单值 | **O(7) amortized**（cache hit） |
| Bloom 缓存命中率 | N/A | **≥ 95%**（同一 RG 多次查询） |

## 四、决策日志

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-09-04 | P0 最高：MVCC 一致性是 Auto 迁移可信度的关键 | 数据搬迁 + 版本链 = 数据库正确性 |
| 2026-09-04 | mmap 大文件走 sparse mmap（不一次性 map 整文件） | 避免内存占用爆炸 |
| 2026-09-04 | Bloom 共享 Arc<ColumnBloom> 不可变引用 | 多查询并行无锁，零拷贝 |
