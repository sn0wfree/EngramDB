# v0.14.0 Phase 1.3: C02 AUTO_INCREMENT 实际自增逻辑

> 完成时间：2026-08-04
> 状态：✅ 完成

## 任务内容

为 EngramDB 添加 **AUTO_INCREMENT 自增主键** 完整实现：用户可声明 `id INT AUTO_INCREMENT PRIMARY KEY`，插入时自动分配 ID。

## 实现细节

### Schema 扩展
- `TableDef.next_auto_increment_id: u64` 新增字段，初始值 1
- `ColumnDef.auto_increment: bool` 字段已存在
- serde 自动持久化（catalog + 重启）

### Parser 解析
- sqlparser 0.47 GenericDialect 把 `AUTO_INCREMENT` 解析为 `ColumnOption::DialectSpecific([Token::AUTO_INCREMENT])`
- 解析逻辑：检查 tokens.to_string().to_uppercase() 是否为 "AUTO_INCREMENT" 或 "AUTOINCREMENT"

### Planner 接线
- `plan_create_table` 检测 `c.auto_increment` → 调用 `col.auto_inc()` 设置
- 修复：`auto_increment` 之前未从 sql::ast::ColumnDef 传到 common::types::ColumnDef

### 存储层逻辑
`Table::insert()` 和 `Table::insert_row()` 顶部添加：
```rust
if auto_increment:
    for col_idx in auto_inc_cols:
        match value:
            Value::Null => 自增分配
            Value::Int64(0) / Value::Int32(0) => 自增分配
            Value::Int64(n) if n >= next_id => next_id = n + 1（更新计数器）
            Value::Int32(n) if n >= next_id => next_id = n + 1
            else => 保持
```

### 持久化
- `next_auto_increment_id` 序列化到 `TableDef`
- `serde::Serialize/Deserialize` 自动处理（无需版本迁移）

## 使用示例

```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR
);

INSERT INTO users (name) VALUES ('alice');  -- id=1
INSERT INTO users (name) VALUES ('bob');    -- id=2
INSERT INTO users VALUES (100, 'carol');    -- id=100
INSERT INTO users (name) VALUES ('dave');   -- id=101
```
