# 历史包袱清单与处置（v0.22.4+）

> 日期：2026-10-21  
> 范围：路线图 `EngramDB 后续路线图 v0.23+.md` 校准后，代码侧历史债务盘点。

---

## 一、本次已清

| 项 | 处置 |
|---|---|
| **HAVING 聚合泄漏进投影**（差分 bug） | 聚合后按 SELECT 列表投影（`apply_select_projection_after_aggregate`）；差分测试解除 `#[ignore]` |
| **聚合内表达式被忽略**（`SUM(amount*2)`→`SUM(col0)`） | `AggregateExpr.input_expr` + 执行前物化临时列；差分测试解除 `#[ignore]` |
| **WAL checkpoint `truncate` 截掉标记** | 只写 Checkpoint + sync（上一提交） |
| **P1-1 GROUP BY Value 热路径** | 类型化快路径（上一提交） |
| **`take_front` drain 残留**（executor Limit） | 改为 `from_range(0, n)` |
| **`on_commit` 分层迁移从未接线** | BEGIN/INSERT/UPDATE/DELETE/COMMIT 各提交点调用 `Database::on_commit()` |

## 二、仍挂账（按优先级）

### P0 — 正确性 / 持久化

| 项 | 位置 | 说明 |
|---|---|---|
| WAL 旧段无法回收 | `storage/mod.rs` checkpoint 注释 | checkpoint 后旧记录成孤儿；需 segment rolling（路线图 A1–A2） |
| 列存 DELETE 不可原地删 | `storage/table.rs` / `operators/delete.rs` | 仅 Delta 层可删；需 tombstone + compact |
| 文件头原子性 / 崩溃注入 | 见 `assessment-v0.22.md` | P0 清单已修但部分未在可编译环境复验 |

### P1 — 功能落差

| 项 | 位置 | 说明 |
|---|---|---|
| ReadUncommitted / Serializable | `common/config.rs` | 枚举存在，注释写明未实现 |
| DataFusion 谓词下推 / catalog 加载 | `datafusion_ext/*` | TODO 未接 |
| PREWHERE 完整实现 | `operators/table_scan.rs` | 仅 skip-predicate 简化版 |
| DESC 索引反向扫描 | `sql/planner.rs` | 暂不支持 |
| LogEngine 无 UPDATE/DELETE/UPSERT | `storage/engine.rs` | 引擎语义限制，需文档化或报错面统一 |
| Vector 原生字面量 | `lib.rs` | 仅字符串插入 |

### P2 — 死代码 / 冗余

|---|---|---|

| `executor/arena.rs` | 默认不启用 | 与路线图 P1-3 bumpalo 合并评估 |
