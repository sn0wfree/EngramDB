# v0.14.0 Phase 1.2: T13 DATETIME/TIMESTAMP 类型

> 完成时间：2026-08-04
> 状态：✅ 完成

## 任务内容

为 EngramDB 添加 **时间戳（TIMESTAMP）** 类型，存储为 Unix 毫秒（i64 UTC）。这是 Agent 日志/记忆场景的刚需（事件时间、消息时间戳等）。

## 实现细节

### 类型系统扩展
- `DataType::Timestamp` 新增变体（8 字节）
- `Value::Timestamp(i64)` 新增变体，存储 Unix 毫秒
- variant_rank：Timestamp = 10（追加在最后）
- Ord：直接 `i64.cmp()`（时间戳是 i64 全序）
- Hash：`t.hash()`（与 i64 一致）
- Display：`ts({})` 格式

### 序列化全链路
| 组件 | Tag | 编码 |
|---|---|---|
| column_store `serialize_values` | DataType::Timestamp | i64 little-endian |
| column_store `deserialize_values` | i64 → Timestamp | 8 字节 |
| column_store `data_type_to_u8` | 9 | tag = 9 |
| column_store `values_byte_size` | - | 8 字节 |
| skiplist `encode_value` | TIMESTAMP = 10 | tag + i64 |
| WAL `serialize_value` | 10 | 1 字节 tag + 8 字节 |
| compression `compress` | 复用 Int64 压缩 | - |

### Parser
- `sqlast::DataType::Timestamp(_, _)` → `DataType::Timestamp`
- `sqlast::DataType::Datetime(_)` → `DataType::Timestamp`

### 类型转换
- optimizer `eval_constant_cast`：
  - TIMESTAMP ← Int32 / Int64
  - VARCHAR ← Timestamp

### Arrow 映射
- `Value::Timestamp` → `ArrowDataType::Int64`

## 时间范围

- i64 毫秒 Unix 时间戳覆盖范围约 ±292,000,000 年
- 实际应用：1970-01-01 ~ 2262-04-11 是正数范围
- 超过范围使用负数时间戳（历史时间）
