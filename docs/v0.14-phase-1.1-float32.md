# v0.14.0 Phase 1.1: T07 FLOAT32 类型

> 完成时间：2026-08-04
> 状态：✅ 完成

## 任务内容

为 EngramDB 添加 **单精度浮点数（FLOAT32/f32）** 类型支持，节省 50% 存储空间，适合 ML embedding、科学计算等场景。

## 实现细节

### 类型系统扩展
- `DataType::Float32` 新增变体（4 字节）
- `Value::Float32(f32)` 新增变体
- variant_rank：Float32 = 4（Float64 调整为 5）
- Ord 实现：`to_bits().cmp()` 全序比较（与 Float64 一致）
- Hash 实现：`to_bits().hash()`（与 Float64 一致）
- Display 实现：`{}` 格式

### 序列化全链路
| 组件 | Tag/位置 | 编码 |
|---|---|---|
| column_store `serialize_values` | DataType::Float32 | 4 字节紧凑 |
| column_store `deserialize_values` | Float32 | 4 字节解析 |
| column_store `data_type_to_u8` | 8 | tag = 8 |
| column_store `values_byte_size` | - | 4 字节 |
| skiplist `encode_value` | FLOAT32 = 9 | 自描述 tag |
| skiplist `decode_value` | FLOAT32 | 自描述解析 |
| WAL `serialize_value` | 9 | 1 字节 tag + 4 字节数据 |
| WAL `deserialize_value` | 9 | 解析 |
| compression `compress_float32` | RLE | 4 字节模式压缩 |

### Parser
- `sqlast::DataType::Float4` (PostgreSQL) → `DataType::Float32`
- `sqlast::DataType::Float(_)` 仍为 Float64

### 类型转换
- optimizer `eval_constant_cast`：
  - FLOAT32 ← Float64 / Int32 / Int64
  - VARCHAR ← Float32

### Arrow 映射
- `Value::Float32` → `ArrowDataType::Float64`（简化映射，Arrow 侧无 Float32）
