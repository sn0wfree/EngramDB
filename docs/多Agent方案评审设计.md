## §0 一页摘要

### 初判：**有条件通过**（Conditional GO）——不具备“立即开跑”条件，具备“评审议程走完即开跑”条件

| 项 | 内容 |
|---|---|
| **开跑前必须关闭** | ① H1 长跑不膨胀测试形态落地到任务卡 ② H2 A4b 门禁硬化方案选定 ③ Q1 并行度 / Q2 DELETE 进否 W1 / Q5 执行载体 三项拍板 ④ H5 bench 参考环境选定 ⑤ 第一批 spawn 的 DoD 与证据模板定稿 |
| **最大风险** | **单一可信验证链未闭合**：本地 SAC 不可编译（已证实）→ 一切“完成”依赖 CI/WSL；CI 排队是物理串行点，多 Agent 并行度一旦高于合并消化能力，会制造“假并行、真排队”与 merge 债 |
| **第二风险** | 列存 DELETE（串行深工）与崩溃/恢复语义交叉；**不可逆点**若无设计门槛与 revert 预案，可能破坏旧 `.hdb` 兼容 |
| **明确不阻塞开跑** | v0.24/v0.25 范围、Agent-Memory 应用层边界、datafusion 全 feature clippy——均已冻结或降级，不影响 W0–W2 |

**一句话**：方案骨架（所有权 / WSL-CI 门禁 / 范围冻结）**成立**（已证实自材料）；硬伤 H1–H5 处置已写入计划但**决议未落印**；把 Q1/Q2/Q5 拍掉即可开第一批。

## §7 红灯与阻断条件

### 7.1 必须停止开跑 / 停波次（红灯）

| DELETE 无设计签字即改格式 | H3 | **红灯**，撤销工作分支 |
| crash 测试 flaky &gt;10%（材料推断阈值，待 H4 核准） | H4 | 降级 nightly，PR 禁止 |
| 新警告 / 新 `println!` 门禁 | D1 修订 | merge 拒绝 |
| Agent 改热点文件未授权 | 所有权表 | merge 拒绝 |

### 7.2 允许带 KNOWN-GAP 豁免开跑

| 类型 | 例 | 条件 |
|---|---|---|
| 产品语义限制 | LogEngine 无 UPDATE/DELETE | 文档化 + 测试显式预期错误 |
| 第三方依赖 | datafusion/chrono clippy | Q3=A 时书面豁免 |
| 长耗时套件 | 随机 crash | nightly，不进 PR |

### 7.3 豁免格式（强制）

```markdown
## GAP-<YYYYMMDD>-<序号>
- 描述：
- 影响面：
- 测试中的表现：#[ignore = "GAP-..."] 或 显式断言错误类型
- 豁免人 / 日期：
- 退出条件（何时删豁免）：
- 关联：历史包袱清单 行 / issue
```

**禁止**：仅 `println!`、仅注释、仅口头。

### 7.4 不可逆点专表

| 点 | 不可逆内容 | 前置门禁 | 回退 |
|---|---|---|---|
| 列存 DELETE | 行数据/文件格式 | H3 设计签字 + 分阶段测试 | revert commit + 版本头拒读策略 |
| 文件头原子性 | 打开/恢复语义 | H4 kill 点④ 用例绿 | revert；双头冗余若有则切换 |
| P0 复验 | GO 依据 | WSL/CI 全量记录 | 无代码回退，只能重验 |
| clippy 阻塞恢复 | CI 门禁配置 | 警告清零提交先行 | `continue-on-error` 一键回加 |
